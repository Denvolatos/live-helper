# 直播助手 v2（开发中，网页界面版）

后端沿用 Python（复用上级目录的 `core.py`），界面换成网页技术：pywebview + 纯 HTML/CSS/JS（Windows 用系统自带的 WebView2）。没有前端框架、没有 npm、不用外部 CDN。

## 运行

```
pip install pywebview
python v2/app_web.py          # 真实联网
python v2/app_web.py --demo   # 假数据（截图/演示）
python v2/test_v2_api.py      # 单元测试（不联网）
python v2/test_v2_api.py --live   # 各平台联网各查一次，打印条数和耗时
python v2/gui_check.py <截图目录> # 仅 Windows：演示模式起窗口、截图、统计帧间隔
```

演示模式的特殊查询词：含“风控”→斗鱼报风控，含“超时”→虎牙超时，含“无结果”→空结果，含“慢”→多等 1.5 秒（看加载状态）。

## 目录

| 文件 | 作用 |
|---|---|
| `app_web.py` | 入口：创建 pywebview 窗口，挂上 `Api` |
| `api.py` | 前端调用的后端接口：并行搜索、链接/房间号解析、错误文案、过期结果丢弃。只依赖 `core.py`，不依赖界面库，两个系统通用 |
| `web/index.html` `app.css` `app.js` | 界面（深浅色用 CSS 变量） |
| `test_v2_api.py` | api 层单元测试（假数据） |
| `gui_check.py` | 界面自检脚本 |

平台相关的部分（播放器、安装、打包、弹幕悬浮层）将来单独成层，本步没有碰。

## 本步做了什么

- 窗口：左侧收藏栏（占位“暂无收藏”）、顶部搜索框 + 虎牙/斗鱼/B站 勾选 + 深浅色切换、主播卡片网格（窗口缩放自动重排，最小 760×520）。
- 搜索：主播名回车搜索；粘贴房间链接只查对应平台；纯数字同时按房间号查和按名字搜。三平台并行，单个平台失败只在上方提示条显示原因（斗鱼风控会建议改用房间号）。搜索在后台线程；快速连按只保留最后一次结果（后端和前端各挡一层）。
- 头像：直接 `<img>`（不带 Referer），加载失败换成“首字 + 渐变底色”占位。
- 主题：启动前就设好 `data-theme`，切换时只改变量，颜色有过渡。

## 没做

收藏、播放（卡片上的“播放”按钮禁用，点击提示“下一步实现”）、画质、续播、更新检查、弹幕、打包、macOS 实测。

## 已知问题 / 未验证

- 拖动流畅度没有用真实鼠标拖动测过，只做了程序化缩放/移动的页面帧间隔统计，**需要用户目视确认手感**。
- 深色模式下 Windows 原生标题栏仍是白色（系统控件，pywebview 未改）。
- 头像在真实平台上是否被防盗链拦截，未在界面里验证（演示模式没有头像）。
- macOS 上 pywebview（WKWebView）未测试。
- 斗鱼搜索仍可能被风控，这是接口限制，不是本步的 bug。
